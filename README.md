# Ashutosh’s Pocket Portfolio

A handheld portfolio inspired by Martin Gauer’s site, with an original CSS console shell, LCD menu, and content personalized for Ashutosh.

## Preview

Run `python3 -m http.server 8000 --bind 127.0.0.1` here and open http://127.0.0.1:8000/.

- Toggle the power switch or press START/A to boot.
- Use the directional pad or SELECT to change sections. A opens; B returns.
- Focus the screen or console controls for arrow-key navigation. Enter opens when the screen is focused; Escape returns.
- Menu entries also respond to clicks and taps.
- The page index provides direct links without console interaction.
- Sound is not included. Reduced-motion preferences disable animations.

The implementation is static HTML/CSS/JavaScript, compatible with the existing GitHub Pages repository. No build dependencies. Google Fonts are optional with local fallbacks. `CNAME` retains ashutoshwahane.dev.
